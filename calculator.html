Per-token rows: input tokens that hit the cache are priced at the cache-read rate and the rest at the normal input rate. Cache-write surcharges, batch discounts, tool fees, long-context premiums on Anthropic and taxes are not included, so real per-token bills for agents are usually a little higher than shown. Agents often make several API calls per user prompt; enter API calls, not chat messages.

When per-token is cheaper (honest note)

  • Low volume. If you make a few dozen modest calls a day, per-token billing often comes in under $19/month. The calculator says so when it happens.
  • High cache-hit, small outputs. Cache reads cost 10% or less of normal input on Anthropic and OpenAI, so a well-cached workload can be much cheaper than its uncached price.
  • Bursty months. A flat plan bills you even in weeks you don't code. Pay-as-you-go doesn't.
  • You already pay for Claude Pro/Max. If Claude Code fits inside your plan's 5-hour and weekly limits, extra API spend may be unnecessary. Max also includes $100 or $200/month of Claude Platform API credits.

FAQ

How much does a coding agent cost per month on the Claude API?

Multiply requests per day by tokens per request and the list price. Example: 300 requests/day with 30,000 input tokens (60% cached) and 1,000 output tokens on Claude Sonnet 5.5 at $2 input, $0.20 cache read and $10 output per million tokens is about $0.0376 per request, or roughly $338/month over 30 days, before cache-write surcharges.

Is a flat-rate LLM API cheaper than paying per token?

Only above a certain volume. At low volume (a few dozen modest calls a day) per-token billing is often under $19/month and is the cheaper choice. For agent workloads that re-send large contexts hundreds of times a day, a flat plan such as APIClaw's $19 to $129/month tiers usually costs less. The calculator shows which side of the line you are on.

What is a request weight?

APIClaw counts heavier models as more than one request against your daily quota. According to APIClaw's public model list, Claude Sonnet 5.5 has a weight of 2, Claude Opus 5.5, Claude Fable 5.1 and GPT-6 Sol a weight of 3, and DeepSeek V4 Pro a weight of 1.

How does OpenRouter pricing compare?

OpenRouter bills the provider's list price per token and charges a 5.5% fee when you buy credits on the Standard plan (8% on Business), so it costs slightly more than going direct for the same model and tokens.

Can Claude Pro or Max replace API spend for Claude Code?

Often, yes, for individual use: Claude Code is included in Pro ($20/month) and Max ($100 or $200/month), with usage limits on a rolling 5-hour window plus weekly limits. Anthropic doesn't publish those limits as request counts, so the calculator can't tell you whether your workload fits.
